# CTF-EL-Djazair Challenges

This repository contains the challenges from CTF-EL-Djazair, the Capture The Flag competition organized by the Algeria Government.

## About

- **Event**: CTF-EL-Djazair
- **Date**: 23/05/2025
- **Organizer**: Algeria Government
- **Status**: Completed ✅

## Repository Contents

This repository includes the original challenge files and problem statements from the competition. Each folder contains the challenges as they were presented during the CTF.

```
├── Blockchain/           # Blockchain security challenges
├── Crypto/              # Cryptography challenges
├── Forensics/           # Digital forensics challenges
├── Misc/                # Miscellaneous challenges
├── OSINT/               # Open Source Intelligence challenges
├── Reverse Engineering/ # Binary analysis and reverse engineering
└── Steganography/       # Hidden information challenges
```

## Usage

Feel free to use these challenges to:
- Practice cybersecurity skills
- Learn different CTF techniques
- Understand various security concepts
- Prepare for future competitions
